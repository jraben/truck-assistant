Pick the screen, then the brain

The Slate ships with no screen and no modem, only a mount and Slate's phone app. CarPlay needs a receiver: an iPad can't be one, so the choice of hardware decides whether CarPlay works.

RECOMMENDED

A · Raspberry Pi 5 + Carlinkit + 10–13" touch

  • Real wireless CarPlay
  • react-carplay (open source) shows CarPlay inside this dashboard
  • CAN HAT reads the truck; GPIO drives relays
  • Needs a car power board (safe shutdown on ignition off)
  • About $300–450 all-in
EASIEST CARPLAY

B · Android tablet / head unit + Carlinkit

  • CarPlay via Autokit app
  • Dashboard runs as a web app beside it, flip between them
  • Less integrated, CarPlay is a separate app
  • About $250–400
NICEST SCREEN

C · iPad on Slate's mount

  • No CarPlay, ever
  • Dashboard as a full-screen web app; phone stays your nav/music
  • Needs a small ESP32/Pi box for truck data and relays
  • Heat: iPads shut down in a hot Arizona cab
ADD-ON

D · ESP32-P4 7–10" display

  • No CarPlay
  • Great as a second screen: gauges + relay buttons
  • Boots in a second, survives heat, cheap ($60–120)
  • Pairs with A, B or C
Build in phases
Phase 1This UI as a web app. Simulated data. Runs on any screen, so you can try it on an iPad or tablet today. Phase 2Pi 5 + Carlinkit on the bench: CarPlay inside the CARPLAY view, and the six upfit relays working. Phase 3Truck arrives: sniff the CAN bus read-only, map speed / SoC / gear. Add TPMS, GPS, rear camera on reverse. Phase 4WOPR voice button, trip log back to the NAS when the truck reaches home Wi-Fi. Phase 5Clean it up to publish: config file for relays, setup script, an image others can flash.
